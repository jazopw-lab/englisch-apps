# Englisch-Apps – Fachschaft Englisch FOSBOS Weiden

Lern-Apps für Schülerinnen und Schüler, gehostet über GitHub Pages: https://jazopw-lab.github.io/englisch-apps/

- `vocab-trainer/` – Vocab Trainer (offen; Fortschritt nur lokal auf dem Gerät)
- `klasse-12/`, `klasse-13/` – Unterseiten „Class 12“ und „Class 13“ (`index.html` je Ordner) mit den Reading Labs und Trainern, **passwortgeschützt** (AES-verschlüsselt mit StatiCrypt, ein Passwort pro Jahrgangsstufe)

Apps mit fremden Texten nur verschlüsselt hier ablegen. Die unverschlüsselten Originale liegen im privaten Repository `englisch-materialien`.


Die Startseite zeigt nur den Vocab Trainer und die Einstiege „Class 12“ / „Class 13“. Neue Apps einer Jahrgangsstufe werden in `klasse-12/index.html` bzw. `klasse-13/index.html` verlinkt.
